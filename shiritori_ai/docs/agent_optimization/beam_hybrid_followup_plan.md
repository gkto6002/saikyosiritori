# Beamハイブリッド深度・幅追試

## 目的

D10000・10辞書seedの比較で、BeamAlphaBetaはAlphaBetaに近い勝率を
約4分の1の判断時間で維持した。BeamPVSは3seedでは好成績だったが、
10seedでは再現しなかった。両方式について、余っている時間を深度または
Beam幅へ振り分けた場合にAlphaBetaへ勝ち越せるかを確認する。

## 事前ベンチマーク

D10000の保存14局面、1手1秒で固定深度を測定した。

| depth | widths | BeamAlphaBeta mean / p95 / timeout | BeamPVS mean / p95 / timeout |
|---:|---|---|---|
| 8 | 8,6,4,2 | 0.194 / 0.309 / 0% | 0.210 / 0.314 / 0% |
| 9 | 8,6,4,2 | 0.369 / 0.782 / 0% | 0.432 / 0.887 / 0% |
| 10 | 8,6,4,2 | 0.604 / 1.000 / 7.1% | 0.682 / 1.006 / 42.9% |
| 8 | 12,8,4,2 | 0.250 / 0.594 / 0% | 0.343 / 0.608 / 0% |
| 9 | 12,8,4,2 | 0.501 / 1.000 / 7.1% | 0.662 / 1.000 / 28.6% |
| 10 | 12,8,4,2 | 0.802 / 1.000 / 35.7% | 0.913 / 1.004 / 71.4% |
| 8 | 12,8,6,4 | 1.000 / 1.000 / 100% | 0.999 / 1.007 / 92.9% |

`12,8,6,4`は末端plyの候補増加が大きすぎるため、本対局から除外する。
D10もタイムアウト率が高いため、適応深度の最大値は9とする。

## 本対局の設定

AlphaBetaは以前採用した初期深度5・最大7・branch 8を維持する。
BeamAlphaBetaとBeamPVSは、それぞれ次の4条件を使用する。

| suffix | 初期深度 | 最大深度 | Beam幅 |
|---|---:|---:|---|
| baseline | 7 | 8 | 8,6,4,2 |
| deep | 8 | 9 | 8,6,4,2 |
| wide | 7 | 8 | 12,8,4,2 |
| deep_wide | 8 | 9 | 12,8,4,2 |

全設定で適応深度を有効にし、目標時間0.6秒、低下閾値0.95、
回復閾値0.6、回復待ち2手とする。

8変種をD10000の辞書seed 0〜9でAlphaBetaと先後入替するため、
対局数は160局となる。同じ辞書・同じ座席では変種間で同じ乱数seedを使い、
無関係なtie-break seedの差を抑える。
