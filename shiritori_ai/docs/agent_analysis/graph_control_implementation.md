# GraphControlAgent 実装設計

## 位置づけ

GraphControlAgentは、この研究で追加する最後の独立単体エージェントである。
HybridAgentは今回実装しない。Minimax、AlphaBeta、PVS、Beamのような再帰探索も、
MonteCarloのようなランダムプレイアウトも行わず、候補を一手適用した後の
残存多重有向グラフを評価する。

AI対AIの状態は`EdgeDictionary`と`AIEdgeState`だけを使う。具体語、word ID、
使用済み単語集合は持たない。同じ開始文字・終了文字の語は一つの辺種別と
残存多重度として扱う。候補詳細ログで要求される「候補単語」は、既存の
辺専用設計を壊さないため、辺種別、開始・終了文字、残存多重度として保存する。
人間対AIだけは`HumanRuntimeState`で具体語を割り当てる。

## 特徴

候補辺を`apply_edge`した状態で次を計測し、必ず`undo_edge`する。

- 相手の合法語数、安全語数、危険語数
- 相手開始文字から到達可能な文字数と残存多重辺数
- 相手開始文字の強連結成分の頂点数、内部多重辺数、出口多重辺数
- 2手以内、3手以内の到達文字数
- 2手範囲の低出次数文字率、3手範囲の行き止まり率
- 次文字候補数と終了文字への集中度
- 残存語数または文字数で正規化した全特徴

`ん`終端は既存ルールどおり即時敗北、相手合法手0は即時勝利として扱う。
構造差の診断がこの終端スコアに埋もれないよう、全候補の評価統計に加えて
即時勝敗候補を除いた`structural_*`統計も保存する。

## 初期重み

重みは`src/graph_control.py`の`GraphControlWeights`へ集約した。相手の選択肢、
到達範囲、SCCと出口を小さくする方向、低出次数・行き止まり・終了文字集中を
大きくする方向である。重み探索は行わず、解釈可能な初期値を固定した。

## 計算量対策

辺数の適用と復元、語数・安全語数・辺種類数・active maskの更新は既存
`AIEdgeState`の定数時間差分更新を使う。候補適用後も接続の有無が変わらない
多重辺については、同じ相手開始文字の到達集合、SCC、深さ2/3集合を手番内で
共有する。多重辺本数に依存する内部辺数などは候補ごとに再集計する。
キャッシュは一手の評価中だけ存在し、異なる局面間では共有しない。

## 比較対象と除外

正式比較はRandom、Greedy、MonteCarlo、Minimax、AlphaBeta、PVS、
BeamNegamax、GraphControlの8種である。`AggressivePVSAgent`は現在のPVSの
後方互換別名で実装差がないため、重複比較から除外した。

## 再現性と再開

比較ランナーは対局ID、コミットID、ソース指紋、設定ハッシュ、辞書ファイル
SHA256、辞書内部ハッシュを保存する。決定論同士は同一条件を反復しない。
RandomまたはMonteCarloを含む組は独立seedで5反復する。完了対局はJSON Linesへ
即時追記し、同じrun hashだけを再利用する。

実行方法はREADMEの「GraphControlAgentと全AI比較」を参照。
